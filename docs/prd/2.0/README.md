# Ratel 2.0：知识工作能力演进

> 2026-10-18 · 需求草案 v0.1 · 总体方向已确认，需求细目与阶段范围待审阅。

**构建面向 AI 时代的知识沉淀、消费与生产能力。**

让已有知识能够支撑人与 AI 的工作，让工作中形成的新知识和成果得到积累，并在后续使用中不断完善。

本轮先明确目标、问题、需求和版本选择原则。2.0 表示产品演进方向，不代表全部候选能力都进入 2.0.0；本目录不包含实施计划，也不批准任何技术方案。

讨论主线是：资料、经验和想法进入工作区，经整理与确认后供任务使用；人与 AI 在任务中形成成果与新判断，使用反馈再推动知识修订。多格式文件、检索、场景配置和 Agent 扩展服务于这一过程。

## 确认边界

已确认的是产品目标：知识有处理过程，Ratel 要让知识更好地被 AI 使用，并支持沉淀、生产、消费和持续演进。用户已授权按这一方向编写首版文档。

尚待确认的是本稿各需求的验收条件、优先级、第一条交付链路、具体格式、场景范围和版本/分支安排。新增建议均按候选处理，不以“文档已经写了”代替用户决定。下一步先审阅本文档，文档确认后再讨论 spec 拆分。
