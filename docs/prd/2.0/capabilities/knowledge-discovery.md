# 知识检索与来源定位

> 2026-10-23 · 能力分册草案，待文档确认；不构成选型、实施或发布承诺。共同安全与验收原则见[总体 PRD](../README.md)。

## 1. 用户问题与范围

用户需要从大量材料中找到事实、沿真实引用回溯，并核查出处。知识可发现性由检索、索引和工具提供，不依赖组织 Skill、入口笔记或用户预先清理目录。关联需求：`REQ-2-KC-001`、`REQ-2-WS-001`。

## 2. 检索与来源要求

| 能力 | 产品要求 | 验收边界 |
|---|---|---|
| 搜索范围与覆盖 | 统一说明选定、排除、未处理、部分覆盖和失败内容 | 无命中不等于未覆盖材料不存在相关信息 |
| 原词查找 | Markdown 与可读派生内容均可原词查找，返回实际命中与必要上下文 | 办公文件不能只进入向量搜索，不能以语义相近冒充原词命中 |
| 语义检索 | 对提取后的文字与必要结构建索引，复用现有 embedding 能力并测质量 | 文件后缀不决定模型是否够用，未处理内容不算已覆盖 |
| 链检索与反向追踪 | 从已知笔记、真实引用与反向链接继续查找 | 宿主已有链接与模型推测关系分开，不能虚构引用 |
| 原件与位置 | 结果指向同一原件身份、对应版本及实际可核查位置 | 派生文本不当另一份原件，无法精确跳转时如实降级 |
| 上下文读取 | 按需读取命中处及必要相邻内容，保留解释数字与文字所需结构 | 不用截断片段制造确定结论，不默认整件灌入上下文 |
| 更新与失效 | 原件变更时结果反映待更新、当前或失效状态 | 一致性要求引用[材料分册](material-access.md)，不独立维护第二套更新规则 |

## 3. 来源核查与使用边界

笔记可考虑标题或段落，PDF/PPT 考虑页或幻灯片，Excel 考虑工作表与区域，并保留表头和单位；Word 不默认稳定页码。具体格式范围在[材料分册](material-access.md)维护。

有冲突、新旧版本或跨项目相似内容时，应展示依据与不确定性，不能按文件名、时间或排序自动裁定当前有效决定。搜索结果和工具返回都是数据，不自动获得指令与操作权限。

更完整的知识效力、适用条件与阶段上下文选择仍属总体需求，尚未在本轮拆成交付故事；不得将基础来源标记等同于已经实现知识有效性判断。

## 4. 验收与故事覆盖

| 故事或能力 | 验收要求 |
|---|---|
| US-2-004 | 在笔记与已提取材料中找到真实原词、上下文及一致的原件来源 |
| US-2-005 | 用含义找到可核查材料，说明实际覆盖，不对二进制直接向量化 |
| US-2-002～003、006～007、009～010 | 与格式接入共同验证定位、查看和变更后来源一致性 |
| 链检索与反向追踪 | 作为搜索底座增强共同验收，不另立产品故事；按已知材料沿真实引用及反向链接找到目标、方向和原文位置；既有能力回归与新增缺口分别记录 |

### 检索质量验收

用虚构或脱敏、有人工核查依据的材料和查询，分别检查搜索底座返回结果与 Agent 使用结果。搜索未召回正确依据、上下文不足和模型拿到依据后使用错误分开记录。

| 任务 | 验收依据 |
|---|---|
| 原词查找 | 核对已知出现位置；约定 PDF 断行、PPT 文本框拆分等提取情形的匹配边界，不以语义相近代替原词命中 |
| 换种说法 | 用同义与模糊查询检查人工标注的正确依据在前若干条结果中的召回，同时测量响应时间 |
| 上下文完整性 | 命中包含必要相邻文字；数字附带表头、单位和工作表位置，避免孤立数值误导 |
| 混合材料 | 同一范围覆盖笔记和已处理的办公材料；指向原件，不把缓存作为重复原件 |
| 链与反向追踪 | 沿真实链接或引用返回对应材料及可核查位置，方向正确；推测关系与真实引用分开 |
| 相似与旧版本 | 通过来源和版本信息区分同名项目、旧方案及不适用内容；排序不代替效力判断 |
| 无结果与覆盖不足 | 明示已搜索范围、未处理、失败、扫描盲区及排除内容，不将无命中解释为库内不存在 |

先确定样本、预期依据与评价方法，再用现有 embedding 测基线。前若干条的数量、召回与延迟门槛在样本实测后确认，不能以一次强模型成功代表所有配置。质量验收不预设更换 embedding 或新增模型。

范围收回同时覆盖派生内容与在途任务，按[材料分册](material-access.md)执行；不能仅在原件读取入口过滤权限。
