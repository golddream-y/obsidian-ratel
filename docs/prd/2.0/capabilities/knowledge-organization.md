# 知识组织

> 2026-10-23 · 能力分册草案，待文档确认；不构成选型、实施或发布承诺。共同安全与验收原则见[总体 PRD](../README.md)。

## 1. 用户问题与范围

材料即使可检索，也可能缺少易读的主题入口、有效引用和适合当前工作的组织。该分册讨论组织效率，关联 `REQ-2-KS-001`、`REQ-2-KC-001`；检索发现的职责在[知识检索与来源定位](knowledge-discovery.md)。

优先考虑内置 Skill 配合库工具，分析现状、提出局部建议、按授权执行并核查。无需预先整理全库，也不要求统一目录、自动知识图谱或从用户工作中提炼个人方法。

## 2. 产品行为与边界

| 项目 | 建议做法 | 验证要求 |
|---|---|---|
| 未整理的材料 | 按原位置处理与索引，使用原词、语义及真实链接检索 | 没有组织 Skill 或入口笔记也能查找 |
| 组织现状分析 | 内置 Skill 先检查目录、标签、链接和已有入口，再提出局部改进 | 不先套统一目录，不强制全库搬迁 |
| 入口与引用维护 | 使用现有笔记工具维护用户选择的主题或项目入口 | 入口引用真实材料，避免重复维护正文 |
| 调整执行 | Skill 编排，底层工具执行具体修改 | 现有授权有效、覆盖范围清楚、修改可核查 |
| 组织后的收益 | 比较同一任务的查找和阅读过程 | 证明更容易使用，而不是仅生成更多索引笔记 |

组织 Skill 编排判断与步骤；目录、属性、链接查询，读写、移动及权限检查由可靠工具承担。知识笔记承载具体内容，Skill 表达操作方法；被检索到的知识不能自行提升指令或授权效力。

## 3. 人工确认与异常处理

建议应说明目录、入口和引用的拟改动及影响范围，允许部分采用。拒绝不写入，已有人工入口和说明不被静默覆盖。执行中只修改授权范围，保留部分成功与失败的真实结果；引用修复和恢复按工具实际能力说明，不承诺整次操作必然完全回退。

材料变化后的入口维护优先由用户按需发起，提出局部差异，不为保持模板整齐重写全部正文。没有组织 Skill 或入口笔记时，材料仍可正常检索。

## 4. 验收与关联故事

| 故事 | 可检查结果 |
|---|---|
| US-2-012 | 根据真实目录、属性、链接与入口说明局部组织问题 |
| US-2-013 | 用户理解调整与影响后选择全部、部分采用或拒绝 |
| US-2-014 | 入口链接真实材料并说明用途，不复制所有正文 |
| US-2-015 | 授权修改与引用核查有实际结果，部分失败不冒充完成 |
| US-2-016 | 按需刷新新增、缺失与失效引用，保留人工编辑 |

US-2-012、013、015 按一次局部组织任务联合验收，分别追踪分析、选择与执行条件，不将流程步骤拆成三次产品交付。US-2-014 建立入口和 US-2-016 刷新入口可独立验收。

用同一组查找任务比较组织前后的寻找、理解与维护负担；不能只以生成了多少入口笔记作为收益。正文见[用户故事](../stories/README.md)。

## 5. 待决问题与依赖

内置 Skill 的最小范围、建议粒度、入口维护方式及工具现有能力缺口待验证；不提前承诺自动搬迁与全库治理。组织工作可使用已有库工具，与多格式扩展并行验证，具体批次在[路线](../../../roadmap/2.0.md)统一安排。
