# Ratel 产品总纲

Ratel 是主动智能的 Obsidian 知识与环境管理 Agent。它让知识库和工作环境在合适时间参与工作，而不是只等用户搜索和手动折腾。

## 产品全貌

| 层级 | 用户得到什么 |
|---|---|
| 支柱 A 主动智能 | 不用每天先打开聊天：基于日记和记忆约定做简报、建议，进洞察收件箱，必要时用 Obsidian 通知触达 |
| 支柱 B 图知识管理 | 找回旧笔记、带着来源回答；发现断链与重复；跨笔记挖主题、关系与缺口 |
| 支柱 C 场景生态 | 管家：按环境场景把多插件底座装好、配好、能调；平台提供手与契约，生态作者能快速写出场景；改环境能查能撤。不含定时总结 |
| 开放底座 | 模型可换；工具 / Schema / Skill 机制（含内置 Skill）可被场景复用 |
| 信任护栏 | 本地优先、黑名单、最小披露、改笔记和改环境都要确认 |

底座、检索引用和 Goal 已经能用。主动闭环、熵治理与挖掘、环境场景管家还在总纲里，尚未当产品交出去。
