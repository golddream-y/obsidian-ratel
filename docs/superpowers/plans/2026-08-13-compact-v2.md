# P-COMPACT-V2 — 投影压缩 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 聊天记录不动；发给模型的上下文走标记投影 + 工具结果瘦身；手动/自动压缩与一次 CONTEXT_OVERFLOW 重试。

**Architecture:** 纯函数 `projectView` 把 `Session.messages` 投影成 head（摘要 system）+ tail（microcompact 原文）。`toMessages()` 只把 tail 交给现有 `trimHistory`。`compactSession` 改为 `appendCompactMarker`，禁止 `resetSession`。UI 用 `Message.role === 'compact'` 画分隔。`plugin.ask` 在本轮第一次 LLM 就 overflow 时 compact 后 `skipAddUserMessage` 再进 loop。

**Tech Stack:** TypeScript / Svelte 5 / Vitest / Obsidian Plugin / i18n

**Spec:** [S-COMPACT-V2](../specs/2026-08-13-compact-v2-design.md)

## Global Constraints

- 用户可见字符串走 i18n（`zh.ts` + `en.ts` + `types.ts`），禁止硬编码
- 发给模型的占位 `[compacted] …` 与摘要 prompt **不**走 i18n
- 测试 `it(...)` 中文：`行为 - 条件 - 期望结果`
- 文件头 / 导出 JSDoc 按 AGENTS.md 中文
- **禁止** compact 路径调用 `resetSession` / `showCompactConfirm`
- **禁止** 修改 `session.messages` 正文来「压缩」
- 不引入新 npm 依赖
- 常量：`KEEP_RECENT_TOOL_RESULTS=5`、`MAX_RESTORED_NOTE_PATHS=5`、`AUTO_COMPACT_THRESHOLD_PCT=85`、`AUTO_COMPACT_CIRCUIT_LIMIT=3`、`MIN_TRANSCRIPT_TO_COMPACT=3`、Notice 已压缩 2500ms

```typescript
export const KEEP_RECENT_TOOL_RESULTS = 5;
export const MAX_RESTORED_NOTE_PATHS = 5;
export const AUTO_COMPACT_THRESHOLD_PCT = 85;
export const AUTO_COMPACT_CIRCUIT_LIMIT = 3;
export const MIN_TRANSCRIPT_TO_COMPACT = 3;
export const COMPACT_SUMMARY_PREFIX = '[compact 摘要]\n';

export const FOLDABLE_TOOL_NAMES = new Set([
	'read_note', 'search_vault', 'grep', 'glob', 'list_files', 'search_memory',
]);

export interface ProjectedTranscript {
	head: ChatMessage[];
	tail: ChatMessage[];
}

export function resolveToolMeta(messages: ChatMessage[], toolIndex: number): { name: string; args: Record<string, unknown> } | null
export function formatCompactedPlaceholder(name: string, args: Record<string, unknown>, chars: number): string
export function microcompactMessages(messages: ChatMessage[], keepRecent?: number): ChatMessage[]
export function projectView(messages: ChatMessage[], markers: CompactMarker[] | undefined): ProjectedTranscript
export function extractRestoredNotePaths(messages: ChatMessage[], from: number, toInclusive: number): string[]
export function isPromptTooLong(err: unknown): boolean
export function shouldAutoCompact(percentage: number, enabled: boolean, circuitOpen: boolean): boolean

export class CompactCircuitBreaker {
	fail(sessionId: string): void
	succeed(sessionId: string): void
	isOpen(sessionId: string): boolean
}
```

实现要点：
- `resolveToolMeta`：从 `toolIndex` 向前找 `role==='assistant' && toolCallId` 相同者。
- `microcompactMessages`：拷贝数组；收集 `role==='tool'` 下标；除最后 `keepRecent` 个外，若 meta.name 在 FOLDABLE 且 content 不以 `Error:` 开头，替换 content 为 placeholder，**不改**其它字段。
- `projectView`：`latest = markers?.at(-1)`；无则 `{ head:[], tail: microcompact(sanitize(messages)) }`；有则 head 为摘要 system（前缀 `COMPACT_SUMMARY_PREFIX`）+ 若 `restoredNotePaths.length` 再加一条 `最近读过的笔记（按需 read_note）:\n- path`；tail = slice(afterIndex+1) 再 microcompact + sanitize。
- `extractRestoredNotePaths`：从 toInclusive 倒扫到 from，assistant read_note 且 `typeof toolArgs.path === 'string' && path.trim()`，去重保近到远，截断 5。
- `isPromptTooLong`：`status===413` 或 String(message) 匹配 `/prompt too long|context length|maximum context|上下文过长|too many tokens/i`。
- `shouldAutoCompact`：`enabled && !circuitOpen && percentage >= AUTO_COMPACT_THRESHOLD_PCT`。
- 断路器内部 `Map<string, number>`，fail 自增，`>= CIRCUIT_LIMIT` 为 open；succeed delete。

依赖：`sanitizeToolMessageOrder` from `./tool-message-align`；`CompactMarker` from `../ports/persistence`（Task 2 才加类型时：本 Task **先在 compact-project.ts 内 export 同形 `CompactMarker` 再 Task 2 改成从 persistence 进口** — 不允许。**本 Task 在 persistence.ts 只加类型**，不改行为。）

```typescript
export interface CompactResult {
	summary: string;
	marker?: CompactMarker;
	skipped?: boolean;
}

export async function compactSession(
	ctx: ContextManager,
	llm: LLMClient,
	sessionId: string,
	overrides: OverrideMap = {},
): Promise<CompactResult> {
	await ctx.load(sessionId);
	const transcript = ctx.getTranscript();
	const last = transcript.length ? ctx.session 不直接碰私有 — 用 transcript
	const markers = /* 需要读现有 markers：给 ContextManager 加 getCompactMarkers(): CompactMarker[] */
	const { tail } = projectView(transcript, markers);
	const compactable = tail.filter((m) => m.role !== 'system');
	if (compactable.length <= MIN_TRANSCRIPT_TO_COMPACT) {
		return { summary: '', skipped: true };
	}
	const history = projectView(transcript, markers);
	const historyText = [...history.head, ...history.tail]
		.map((m) => `${m.role}: ${m.content}`)
		.join('\n');
	const llmMessages = composeCompactMessages({ history: historyText }, overrides);
	const summary = await collectStream(llm.chat({ messages: llmMessages }));
	if (!summary.trim()) throw new Error(tNow('error.compact.emptySummary'));
	const afterIndex = transcript.length - 1;
	const marker: CompactMarker = {
		afterIndex,
		summary: summary.trim(),
		restoredNotePaths: extractRestoredNotePaths(transcript, 0, afterIndex),
		at: Date.now(),
	};
	await ctx.appendCompactMarker(marker);
	return { summary: marker.summary, marker };
}
```

```typescript
async function handleCompact() {
	if (isCompacting || isRunning) return;
	isCompacting = true;
	const runningId = newMessageId();
	messages = [...messages, { id: runningId, role: 'compact', compactPhase: 'running', segments: [] }];
	try {
		const ctx = plugin.createContext();
		const result = await compactSession(ctx, plugin.llm, sessionId, plugin.settings.promptOverrides);
		if (result.skipped) {
			messages = messages.filter((m) => m.id !== runningId);
			new Notice(tNow('chat.compact.tooShort'), 2500);
			return;
		}
		await ctx.load(sessionId);
		const s = /* 用 persistence get 或 ctx.getTranscript + getCompactMarkers */
		messages = hydrateSessionMessages(ctx.getTranscript(), {
			markers: ctx.getCompactMarkers(),
			resolveMcpServerLabel,
		});
		new Notice(tNow('chat.compacted'), 2500);
		plugin.userStatus.patchContextUsage({
			usedTokens: ctx.tokenCount(),
			maxTokens: getEffectiveChatModelMaxTokens(plugin.settings),
			source: 'estimate',
		});
	} catch (err) {
		messages = messages.map((m) =>
			m.id === runningId ? { ...m, compactPhase: 'failed' as const } : m,
		);
		new Notice(tNow('chat.error.compactFailed', { message: err instanceof Error ? err.message : String(err) }), 5000);
		setTimeout(() => {
			messages = messages.filter((m) => m.id !== runningId);
		}, 2500);
	} finally {
		isCompacting = false;
	}
}
```

```typescript
let skipAdd = false;
for (let attempt = 0; attempt < 2; attempt++) {
	let overflow = false;
	for await (const ev of agentLoop(..., skipAdd)) {
		if (ev.type === 'error' && ev.payload.code === 'CONTEXT_OVERFLOW' && attempt === 0) {
			overflow = true;
			break;
		}
		yield ev;
	}
	if (!overflow) return;
	try {
		const cctx = this.createContext();
		const r = await compactSession(cctx, this.llm, sessionId, this.settings.promptOverrides);
		if (r.skipped) {
			yield { type: 'error', payload: { code: 'LLM_ERROR', message: '上下文过长且无法压缩' } };
			return;
		}
	} catch (e) {
		yield { type: 'error', payload: { code: 'LLM_ERROR', message: e instanceof Error ? e.message : String(e) } };
		return;
	}
	skipAdd = true;
}
```
