## 任务 1：实现并验证完整索引生命周期

1. 先增加会失败的回归测试：进度跨越总超时、异步索引重叠、超时后迟到事件、启动/增量/重建并发、失败不完成、元数据失败传播、成功重启零重复嵌入。运行定向测试记录 RED。
2. 最小实现 Worker 请求活动超时、进度 ID 与串行执行。普通请求仍固定超时；超时后不得让尚未停止的写入与后续操作重叠。双方同时修改协议，不引入轮询。
3. 统一 IndexManager 和 main 的索引调度；smartReindex 失败向上传递；只在显式不兼容分支重建。失败不通知完成，部分错误不冒充成功。
4. 全量输入快照生成对应清单；清单与构建戳写入必须成功后才返回成功。失败不能留下能被误认为完整索引的元数据。旧有效元数据继续复用。
5. 运行定向测试证明 GREEN，完成自审。提交仅本任务源码与测试，保留现有未相关改动。

代码约束：新增错误采用现有国际化入口或结构化内部错误；注释与测试名称使用中文。不得将本机路径写入版本库，不引入原生依赖。
