# S-AGENTS-SESSION — 子目录约束整场会话保留

> 日期: 2026-10-10
> 状态: Active
> Spec ID: **S-AGENTS-SESSION**
> 取代: [S-AGENTS-INJECT](2026-10-02-agents-inject-design.md) 的目标 2、目标 3，以及「追加到系统段、只活一个回合、按目录链去重」。
> 保留: S-AGENTS-INJECT 的目标 1 与目标 4。第一次写入就执行；移动和复制失败只报磁盘原因。库根每轮注入不变。
> 实施文本: [note-agents.md](../../architecture/agent/note-agents.md)。步骤、签名、禁令和验收表以该文为准。本文只登记决策。两者冲突时改架构文档，不要在代码里另选一种做法。

---

## 1. 背景

子目录 `AGENTS.md` 现在由各笔记工具在执行前收集，追加到系统段末尾。去重按整条目录链，记录只活一个用户回合。下一轮用户消息会清空这段。模型直接写一个上一轮读过的目录时，写入先发生，约束要到再下一次请求才回来。先改 `Work/a.md` 再改 `Work/Diary/b.md` 时，`Work` 会被送两次。

Claude Code 的做法是：工作目录及祖先的说明在启动时加载；子目录说明在读到该目录的文件时加载，挂在那次工具结果后面，整场会话保留；压缩之后要再碰到该目录才重新加载。Ratel 要对齐这个留存和位置，文件名仍用 `AGENTS.md`。

系统段在请求前缀里。子目录每多一个就改一次前缀，后面的历史都要重算缓存。所以不能把「整场会话保留」做在系统段上。

---

## 2. 目标

1. 库根 `AGENTS.md` 仍每轮重读，放在系统段，一轮之内不变。
2. 笔记工具第一次碰到某个子目录时加载该目录的 `AGENTS.md`。之后只要这块还在发给模型的历史里，就不再加载。
3. 新加载的正文挂在触发它的那条工具结果上，不进系统段，不进聊天气泡。
4. 去重单位是单个目录。已加载 `Work` 后再碰到 `Work/Diary`，只补 `Work/Diary`。
5. 全量摘要、手动压缩或截断丢掉带块的那条消息之后，下次碰到该目录再加载。移出和单条上限不丢掉块。
6. 经工具成功改写某个子目录的 `AGENTS.md` 后，该目录的旧块作废，下次碰到时加载新版。
7. 加载不改变工具是否执行、不改变工具返回值。

---

## 3. 非目标

- 不读 `CLAUDE.md`、`.claude/rules/`、家目录同名文件。
- 不做 `@path` 导入、按路径匹配的规则、排除名单、HTML 注释剥离。
- 不做 `AGENTS.override.md`。冲突仍靠块尾「近的优先」。
- 不在会话中途检测用户在 Obsidian 里直接改了子目录 `AGENTS.md`。
- 不把子目录约束注入意图分类、压缩摘要、技能沙箱、子代理。
- 不改确认卡。改 `AGENTS.md` 仍必须确认。`copy_note` 的确认仍看 `from`。
- `grep`、`glob`、`list_files`、`search_vault` 不触发加载。
- 不执行约束正文里的命令。

## 4. 详细设计

### 4.1 两处存放

| 内容 | 存放 | 何时更新 |
|---|---|---|
| 库根 | injector 的 `noteAgents` 段 | 每个用户回合开始时重读 |
| 子目录 | tool 消息的 `noteAgents` 字段 | 该次工具调用加载到新目录时写入，之后不改 |

界面、`tool.result` 事件、摘要输入只使用工具结果 `content`。发给模型前，把块接到 `content` 后面，并删掉 `noteAgents` 与 `noteAgentsStale`，适配器不看到这两个字段。

### 4.2 何时加载

权限通过且工具即将执行时加载。参数非法、权限拒绝、执行前钩子拒绝，不加载。执行失败仍保留已经加载的块。取消则这次块不落盘。

同一条回复里的后一个工具必须能看见前一个刚写入的块。不能在这一批工具开始前缓存一份「已加载目录」。

「已加载」按本次发给模型之前的历史重算：消息还带着字段，但已经被压缩投影、移出和截断处理过。不看会话原文（被投影掉的块还在原文里），也不看已经删掉字段的上送包。

### 4.3 改过约束文件

成功改写子目录 `AGENTS.md` 时，只把该文件所在目录标为过期，不把祖先目录一起标过期。`A/B/AGENTS.md` 过期的是 `A/B`。库根不标过期，下一回合重读。旧块留在历史里，新块排在后面。

### 4.4 体积与压缩

单文件 8KB，单块 16KB，超出从最远一层整层丢掉。被丢掉的层不算已加载。一层都留不下就不挂块。

压缩改写消息时必须保留这两个字段。只替换 `content` 的占位不能把字段弄丢。

### 4.5 旧实现

删除按回合、按整条链去重的收集，以及各笔记工具上的注入依赖。加载改到主循环里做一次。
