# 移动与复制笔记 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**目标：** 已有笔记可以移动或复制，正文不进模型输出；工具参数 JSON 不完整时不执行。

**架构：** `VaultPort.renameFile` 调用 `fileManager.renameFile`；`copyFile` 调用 `vault.adapter.copy`。工具层只校验路径并走端口。`agent-loop` 在参数仅为 `{ raw }` 时跳过执行，交回固定中文错误。

**技术栈：** TypeScript、vitest、Obsidian `FileManager` / `DataAdapter`。

**所属 spec：** [S-NOTE-MOVE](../specs/2026-10-01-note-move-design.md)

## Global Constraints

- 移动必须走 `fileManager.renameFile`，不用 `vault.rename`。
- 复制必须走 `adapter.copy`，不改其他笔记的链接，也不改副本内的链接文本。
- 目标已存在则不覆盖。源不存在则报错。父目录不存在则 `createFolder`。
- 参数 JSON 解析失败（`args` 只有 `raw`）时不执行工具。同一轮里解析成功的调用仍执行。
- 用户可见错误走 i18n。交给模型的截断说明与工具 schema 描述不走 i18n。
- 注释与测试描述用中文。测试名：`行为 - 条件 - 期望结果`。
