# P-EVO-A-READ — 图谱原生 Phase A 读工具 + 检索结构信号

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 让 Agent 能按链接图 / tag / frontmatter 精确检索与导航，并让 `search_vault` 结果携带 tags + 反链数，兑现「图谱原生」最小可发版切片。

**Architecture:** 全部结构数据走 `metadataCache`（经 `VaultPort`），不写索引、不改 Worker。新增 `getLinks` / `findByTag` / `findByProperty` / `getVaultStructure` 端口方法；四个只读工具 + `search_vault` 工具层 enrich。`update_frontmatter` 不在本 plan（另开 `P-EVO-A-FM`）。

**Tech Stack:** TypeScript / Vitest / Obsidian `MetadataCache` / 现有 Tool factory + Composer 接线模式

## Global Constraints

- 工具只依赖 `VaultPort`，禁止 `import 'obsidian'`（仅 `obsidian-vault.ts` 可调 Obsidian API）
- 新读工具默认 `toolPermissions: 'allow'` + `readOnly: true`
- 用户可见字符串走 i18n（`settings.toolPermissions.*` / `tool.name.*` / `promptLabel.tool.*`）；LLM schema 描述仍写在 `prompts/defaults/zh.ts`
- 不依赖 `fs`；不改 embedding / Worker / 消息协议
- 测试描述中文：`行为 - 条件 - 期望结果`
- 文件头 / 导出函数按 AGENTS.md 注释规范

```typescript
export interface NoteLinks {
	outgoing: Array<{ path: string; count: number }>;
	backlinks: Array<{ path: string; count: number }>;

}

	orphans?: string[];
```

- [ ] **Step 2: 实现 `ObsidianVault`**

关键约定（写进实现注释）：

1. **`getLinks`**
   - `outgoing`：`resolvedLinks[path]` 的 entries（目标路径 → count）
   - `backlinks`：复用现有 `getBacklinks` 转数组
   - `unresolved`：`metadataCache.unresolvedLinks[path]` 的 entries（link 文本 → count）
2. **`collectTags(path)`（私有 helper）**：合并 `cache.tags`（去掉前导 `#`）与 frontmatter 的 `tags`/`tag`（string | string[]），去重、小写归一可选——**匹配时大小写不敏感，返回保留库内原始写法**。
3. **`findByTag`**：归一化查询 tag（去 `#`）；嵌套前缀：`project` 匹配 `project` 与 `project/foo`；扫 `listMarkdownFiles()`；`limit` 默认 50、硬顶 200。
4. **`findByProperty`**：`getMetadata().frontmatter?.[key]`；`value === undefined` 时表示「键存在」；等值用 `JSON.stringify` 宽松比（覆盖 string/number/boolean）；limit 同 tag。
5. **`getVaultStructure`**：`include` 默认 `['folders','tags','orphans']`
   - `folders`：从 markdown 路径推导唯一父目录列表（排序）
   - `tags`：全库 tag 计数（用 collectTags）
   - `orphans`：无出链且无反链的 `.md`；排除路径前缀 `.`、`templates/`（小写比较）；后续可配置但不在本 plan

```typescript
getLinks(path: string): NoteLinks {
	const resolved = this.app.metadataCache.resolvedLinks[path] ?? {};
	const unresolvedRaw = this.app.metadataCache.unresolvedLinks[path] ?? {};
	const backlinks = this.getBacklinks(path);
	return {
		outgoing: Object.entries(resolved).map(([p, count]) => ({ path: p, count })),
		backlinks: [...backlinks.entries()].map(([p, count]) => ({ path: p, count })),
		unresolved: Object.entries(unresolvedRaw).map(([link, count]) => ({ link, count })),
	};
}
```

（`findByTag` / `findByProperty` / `getVaultStructure` 按上约定完整实现，勿留 stub。）

```typescript
import type { VaultPort } from '../ports/vault';
```

```typescript
// search-by-tag.ts
export function createSearchByTagTool(vault: VaultPort, definition: ToolDefinition): Tool {
	return {
		definition,
		readOnly: true,
		async execute(args) {
			const tag = requireString(args, 'tag', 'tag');
			const limit = optionalNumber(args, 'limit'); // 若无 optionalNumber，用 typeof number 分支，默认交端口
			return vault.findByTag(tag, limit !== undefined ? { limit } : undefined);
		},
	};
}

// search-by-property.ts
export function createSearchByPropertyTool(vault: VaultPort, definition: ToolDefinition): Tool {
	return {
		definition,
		readOnly: true,
		async execute(args) {
			const key = requireString(args, 'key', 'key');
			const value = args.value; // 可省略
			const limit = typeof args.limit === 'number' ? args.limit : undefined;
			return vault.findByProperty(key, value, limit !== undefined ? { limit } : undefined);
		},
	};
}
```
